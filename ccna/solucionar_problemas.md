# Solucionar problemas en dispositivos

Comando **debug** se introduce en modo privilegiado. Permite mostrar al administrador mostrar el proceso del SO, el protocolo, el mecanismo y los mensajes de eventos en tiempo real para su análisis. Para ver más información **debug ?**

Para desactivar la depuración se puede usar los siguientes comandos. El último desactiva todos los debugs activos

````
undebug
undebug all
````

Para mostrar los mensajes de registro usar el comando **terminal monitor**. Para desactivar los mensajes **terminal no monitor**.


Para mostrar información de configuración ver el apartado de **comandos de verificación** de la guía [Configuración básica de dispositivos](/ccna/configuracion_basica/)
